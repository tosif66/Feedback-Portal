## 📌 Overview

Feedback Portal is a web application designed to collect and manage user feedback seamlessly. It provides an intuitive UI for users and a scalable backend for handling feedback data.

This project demonstrates real-world full-stack development skills including API design, CRUD operations, and frontend-backend integration.

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/tosif66/Feedback-Portal.git
cd Feedback-Portal
```

---

### 2️⃣ Setup Backend

```bash
cd backend
npm install
npm run dev
```

---

### 3️⃣ Setup Frontend

```bash
cd frontend
npm install
npm start
```
